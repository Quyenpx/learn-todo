Đóng gói chính Visual Lab

Cần Docker Engine/Desktop đang chạy và Docker Compose. Đây là web tĩnh phục vụ bằng python -m http.server cho thực hành cục bộ. Dockerfile chạy người dùng không có quyền quản trị, cổng 8080; copy cả ví dụ và hướng dẫn để liên kết không bị thiếu. Không có backend hay tài khoản; máy chủ này không dành cho triển khai công khai.

Build, chạy và dừng

# Chạy tại thư mục gốc; -p đặt tên dự án thực hành riêng
docker compose -p visual-lab-practice -f examples/devops/compose.yaml config
docker compose -p visual-lab-practice -f examples/devops/compose.yaml up --build -d
docker compose -p visual-lab-practice -f examples/devops/compose.yaml ps
docker compose -p visual-lab-practice -f examples/devops/compose.yaml logs web
# Sau khi thực hành, chỉ dừng dự án vừa tạo
docker compose -p visual-lab-practice -f examples/devops/compose.yaml down

Mở http://127.0.0.1:8080; kiểm tra ba khóa, hướng dẫn trong thư viện và các file tải. Kết quả mong đợi: web phản hồi, container chuyển sang healthy sau kiểm tra sức khỏe. Compose giới hạn bộ nhớ/CPU, chỉ công bố cổng trên máy cục bộ; không dùng volume. down dọn container/network của dự án, vẫn giữ image đã build. Base image có tag phiên bản nhưng tag có thể thay đổi; khi triển khai cần chọn digest và quy trình cập nhật riêng.

Kubernetes tùy chọn, chỉ trên cluster thử riêng

Cần kubectl, cluster thử đã chọn đúng context và image visual-lab-local:1 đã nạp vào mọi node; hoặc sửa image thành địa chỉ kho riêng mà cluster kéo được. Manifest có Deployment/Service, probe, tài nguyên và quyền tối thiểu. Chưa chạy kiểm thử cluster trong dự án.

kubectl config current-context
# Chỉ tiếp tục khi xác nhận đây là cluster thử riêng
kubectl create namespace visual-lab-practice
kubectl apply -f examples/devops/kubernetes.yaml
kubectl -n visual-lab-practice rollout status deployment/visual-lab
kubectl -n visual-lab-practice port-forward service/visual-lab 8081:8080
# Mở http://127.0.0.1:8081; Ctrl+C để dừng port-forward
kubectl delete -f examples/devops/kubernetes.yaml
# Chỉ xóa namespace nếu chính bạn vừa tạo và không chứa tài nguyên khác
kubectl delete namespace visual-lab-practice

Lỗi thường gặp và giới hạn

  • Docker không kết nối: khởi động Engine/Desktop. Build lần đầu cần mạng tải base image; không cần mô hình hay phụ thuộc máy học.
  • Cổng 8080 đang dùng: sửa cổng máy chủ trong compose.yaml, giữ cổng container 8080. Build context phải là gốc dự án.
  • ImagePullBackOff: image cục bộ chưa có trên node hoặc kho cần quyền kéo. Running nhưng chưa READY: kiểm tra describe/logs/probe/cổng.
  • Lab trình duyệt là terminal mô phỏng; các lệnh Docker/kubectl trên trang này chạy trên máy thật. Manifest không có Gateway, bộ tự co giãn hay hệ thống quan sát. Không triển khai vào cluster đang dùng cho công việc.
