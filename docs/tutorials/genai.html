Hỏi đáp có nguồn trên máy

Đường cơ bản cần Python 3.9 trở lên, chỉ dùng thư viện chuẩn và không gọi mạng. Tại thư mục gốc dự án, chạy chương trình cùng chính sách tiếng Việt mẫu. Các chính sách là dữ liệu minh họa.

Chạy và kiểm chứng

python examples/genai/rag.py --question "Đổi trả sản phẩm trong bao lâu?"
python examples/genai/rag.py --question "Lãi suất vay ngân hàng?"
python examples/genai/rag.py --question "DOI TRA SAN PHAM?" --top-k 1
python -m unittest discover -s examples/tests -v

Câu đầu trả answered: true, nguyên văn chính sách 7 ngày cùng điều kiện hóa đơn/chưa sử dụng và nguồn chinh-sach/doi-tra. Câu thứ hai trả answered: false và nguồn rỗng. Chương trình chuẩn hóa chữ hoa/dấu, bỏ một số từ phổ biến, yêu cầu tối thiểu hai từ khớp và tỷ lệ từ truy vấn khớp từ 0.5. Mỗi mục JSON là một đoạn có sẵn; chương trình không tự chia đoạn.

Đây là phần truy xuất/trích xuất minh họa đường đi của RAG (Retrieval-Augmented Generation: sinh tăng cường truy xuất), chưa có bước sinh bằng mô hình ngôn ngữ. Điểm từ khóa không xác nhận chứng cứ đủ trả lời câu có phủ định hay điều kiện khác. Không có embedding học được, xếp hạng lại, quyền đọc, nhận dạng chỉ dẫn độc hại hay kiểm chứng nghiệp vụ.

Lỗi thường gặp

  • Không tìm thấy file: chạy tại gốc dự án, hoặc truyền --documents đường/dẫn/file.json. JSON cần danh sách không rỗng, mỗi mục có title, source, text là chuỗi không rỗng.
  • Câu hỏi rỗng hoặc --top-k 0: lệnh dừng với mã lỗi 2. Từ đồng nghĩa không khớp: mở rộng dữ liệu hoặc dùng truy xuất ngữ nghĩa thật; không hạ ngưỡng để ép mọi câu có câu trả lời.

Tùy chọn: sinh văn bản bằng mô hình thật

Dùng môi trường Python 3.10 trở lên riêng; tài liệu Transformers hiện kiểm tra với PyTorch 2.5 trở lên. Không chạy phần này trong bộ kiểm thử cơ bản. Qwen2.5-0.5B-Instruct có khoảng 0.49 tỷ tham số, dùng để thử cơ chế. Lần đầu cần mạng để tải trọng số, RAM và đĩa cho framework/mô hình; CPU có thể chậm, không bảo đảm chất lượng tiếng Việt.

# PowerShell; cần cài Python 3.10 trước
py -3.10 -m venv .venv-genai
.\.venv-genai\Scripts\python.exe -m pip install "torch>=2.5" "transformers>=4.37"
# Lưu đoạn Python bên dưới thành thu_model.py, rồi chạy:
.\.venv-genai\Scripts\python.exe thu_model.py
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

name = "Qwen/Qwen2.5-0.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(name)
model = AutoModelForCausalLM.from_pretrained(name).to("cpu").eval()
messages = [{"role": "user", "content": "Giải thích ngắn khái niệm RAG."}]
inputs = tokenizer.apply_chat_template(
    messages, tokenize=True, add_generation_prompt=True,
    return_dict=True, return_tensors="pt")
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=80, do_sample=False)
new_tokens = outputs[0][inputs["input_ids"].shape[-1]:]
print(tokenizer.decode(new_tokens, skip_special_tokens=True))

Đoạn mã dùng mẫu hội thoại và chỉ giải mã token mới sinh, chưa kết nối kho chính sách. Khi ghép RAG thật, phải giữ nguồn, kiểm chứng từng nhận định và từ chối khi tài liệu thiếu. Phần tải/chạy mô hình thật chưa được kiểm thử trong dự án.

Nguồn chính thức

RAG nâng cao, đánh giá RAG, model card Qwen và cài Transformers. Model card cảnh báo Transformers trước 4.37 không hỗ trợ qwen2; phiên bản thực tế cần tương thích với Python/framework. Đối chiếu 07/10/2026.
