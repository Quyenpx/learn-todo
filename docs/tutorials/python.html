Cài đặt Python và chạy notebook bài tập

Mỗi bài trong khóa có mô phỏng chạy từng dòng trên trình duyệt (viết bằng JavaScript, không phải Python thật) và một notebook để bạn chạy Python thật trên máy. Notebook bài tập nằm trong examples/python/notebooks, bản lời giải trong examples/python/solutions.

1. Cài Python và môi trường ảo

Cài Python 3.9 trở lên từ python.org (Windows: tích chọn “Add python.exe to PATH”). Môi trường ảo (virtual environment) giữ thư viện của dự án tách khỏi hệ thống. Tại thư mục gốc dự án:

# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

python --version

2. Cài thư viện và Jupyter

Bài 1–9 chỉ cần Python chuẩn và Jupyter. Bài 10–15 cần NumPy, pandas, matplotlib, scikit-learn và PyTorch.

pip install -r examples/python/requirements.txt
python -c "import numpy, pandas, sklearn, torch; print('Đủ thư viện')"

Nếu cài torch chậm hoặc lỗi, làm theo lệnh dành cho máy của bạn trên pytorch.org (chọn bản CPU là đủ cho khóa học), rồi cài các thư viện còn lại.

3. Làm notebook

jupyter notebook examples/python
  1. Mở notebooks/01_bat_dau.ipynb, chạy từng ô bằng Shift+Enter từ trên xuống.
  2. Ở ô BÀI TẬP, thay mỗi dòng pass # TODO bằng mã của bạn.
  3. Chạy ô kiểm tra. AssertionError kèm gợi ý nghĩa là chưa đúng; sửa rồi chạy lại cả ô bài tập và ô kiểm tra.
  4. Khi đúng hết, ô cuối in “Hoàn thành bài N”. So sánh cách làm với bản lời giải.

Nếu dùng VS Code, cài tiện ích Jupyter và chọn trình thông dịch trong .venv. Google Colab cũng mở được các file .ipynb này.

4. Kiểm thử cho người phát triển

Notebook được sinh từ file nguồn examples/python/src/*.py; không sửa notebook trực tiếp.

python examples/python/build_notebooks.py          # sinh lại notebook sau khi sửa file nguồn
python examples/python/build_notebooks.py --check  # kiểm tra notebook khớp file nguồn
python -m unittest discover -s examples/python/tests -v

Bộ kiểm thử chạy mọi bản lời giải (phải in “Hoàn thành bài N”) và mọi bản bài tập (phải thất bại vì chưa làm). Bài thiếu thư viện được bỏ qua kèm lý do.

Lỗi thường gặp

  • 'python' is not recognized: Python chưa nằm trong PATH; cài lại và tích chọn PATH, hoặc dùng py trên Windows.
  • PowerShell chặn Activate.ps1: chạy Set-ExecutionPolicy -Scope CurrentUser RemoteSigned một lần.
  • ModuleNotFoundError trong notebook: Jupyter đang dùng trình thông dịch khác; chọn kernel của .venv hoặc cài thư viện trong đúng môi trường.
  • Biến “không tồn tại” dù đã khai báo: bạn chưa chạy ô định nghĩa; dùng “Run All” sau khi khởi động lại kernel.
